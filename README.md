## 这段时间在做回想

> 如果三个月后才回到一个项目，AI 还找得到我为什么做了这个决定吗？

这是我在做 **回想 RechoMemory** 时关心的问题。回想从日常聊天里慢慢理解我，记得我经历过什么、在意什么，以及这些想法后来怎么变了。换个对话，它会先找回和当下有关的记忆，再接着聊。
