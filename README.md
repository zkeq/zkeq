## 开源作品

- **[灵感厨房 · Vibe Cook](https://github.com/zkeq/vibe-cook)**：把 HowToCook 做成跟着一步一步就能做完的烹饪 App。我自己用它学做饭，三周后辣椒炒肉和蒜苔炒肉都成了家常菜。[在 Awesome MyGo 查看截图](https://awesomemygo.dev/apps/vibe-cook)
- **[PanelShow](https://github.com/zkeq/Project-PanelShow)**：一个可自托管的作品集工具，让你用项目页和开发时间线讲清楚自己做过什么。
- **[Self-Music](https://github.com/zkeq/Self-Music)**：自建私人音乐库，支持导入网易云音乐元数据、同步歌词和多端播放。
